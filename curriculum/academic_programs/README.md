## 🎯 PowerPoint (.pptx) ဖိုင်များ ထည့်သွင်းနည်း (Instructions)

1. သက်ဆိုင်ရာ သင်ရိုးဖိုဒါအောက်ရှိ **`slides/`** ဖိုဒါထဲသို့ သင် ပြုလုပ်ထားသော PowerPoint presentation ဖိုင်များကို ထည့်ပါ။
2. ဖိုင်အမည်များကို စနစ်တကျ ခွဲခြားနိုင်ရန် အောက်ပါ ပုံစံအတိုင်း ပေးနိုင်ပါသည်-
   - `Module_01_Introduction.pptx`
   - `Module_02_Core_Concepts.pptx`
   - `Lesson_01_Overview.pptx`
3. ထည့်သွင်းပြီးပါက AI Engine သည် အဆိုပါ PowerPoint ဖိုင်များမှ-
   - Slide Title, Bullet Points, နှင့် Speaker Notes များကို ဖတ်ယူပြီး Lesson Content အဖြစ် ပြောင်းလဲပေးခြင်း
   - Code Snippets များကို Syntax-highlighted code blocks အဖြစ် ဖော်ထုတ်ပေးခြင်း
   - Slide တစ်ခုချင်းစီမှ အဓိက အချက်များကို ထုတ်ယူပြီး Quiz Questions & Choices အဖြစ် အလိုအလျောက် တည်ဆောက်ပေးခြင်း
   - Hands-on Lab လေ့ကျင့်ခန်း လိုအပ်ပါက သက်ဆိုင်ရာ Terminal / Lab Scenario နှင့် ချိတ်ဆက်ပေးခြင်း
   တို့ကို အလိုအလျောက် ဆောင်ရွက်ပေးမည် ဖြစ်ပါသည်။
